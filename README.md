# projetoMobileCoding

## Divisão do Projeto:
- Integração com API, criação e estilização das páginas 2 e 3. Criação de rotas e passagem de parâmetros entre
  elas. > *JOÃO CARIBÉ*
  
- Criação de 1 Diretiva Personalizada e 2 Estruturais (2 Personalizadas e 3 Estruturais ao total) > *ANA ANETE* 

- Criação de Pipes, 2 built-in e 1 personalizado > *JOÃO LUCAS*

- Biblioteca HTTPClient e um service para ela > *DANILO LOPES E JOÃO VIEIRA*

## O que é o projeto: 
Um buscador de filmes e séries, com uma página de busca e outra de informações aprofundadas sobre o filme.   
A página de informações contém Sinopse, Poster, Elenco, Diretor, Notas nos sites críticos, Gênero,   
Classificação Indicativa (já convertida para a brasileira através de Pipes e Diretivas), Duração, Premiações e muito mais.

O projeto extrai informações da OMdB API (Open Movie Database)
