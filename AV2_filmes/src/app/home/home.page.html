Observações

Basicamente todos os componentes são puxados da API do ionic, então pra chamar eles vc tem q usar a tag específica deles, q é o nome do componente entre chaves "ion-nomedocomponente"
E depois, o mais IMPORTANTE, vc tem que adicionar a mesma tag no arquivo page.ts da página, no caso dessa aqui é o home.page.ts.
Aí você coloca no import do começo da página ts e depois nos imports do @Components
Mas creio que não será necessário adicionar mais componentes, a maioria já adicionei só é mais estilização mesmo.

Pra mudar o fundo tem q ir na tag ion-content, q é a MÃE de todas aqui, tudo tá dentro dela, é a primeira tag. Apanhei bastante pra descobrir isso
