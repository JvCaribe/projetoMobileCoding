Bem-vindo ao Buscador de Filmes

Projeto desenvolvido para a disciplina de Mobile Coding.

Sobre o Projeto

Nosso sistema funciona como um buscador de filmes, permitindo pesquisar títulos e visualizar informações detalhadas.

  • Página de busca de filmes
  • Página de detalhes do filme
  • Navegação entre páginas usando rotas
  • Integração com API utilizando método GET

Tecnologias Utilizadas

  • Angular + Ionic
  • TypeScript
  • SCSS
  • HTTPClient
  • API de Filmes
  • Pipes personalizados
