Bem-vindo ao Buscador de Filmes e Séries

Projeto desenvolvido para a disciplina de Mobile Coding.

Sobre o Projeto

Nosso sistema funciona como um buscador de filmes e séries, permitindo pesquisar títulos e visualizar informações detalhadas sobre eles.

  • Página de busca de filmes/séries
  • Página de detalhes do filme/série
  • Navegação entre páginas usando rotas e parâmetros
  • Integração com a API OMdB(Open Movie Database)

Tecnologias Utilizadas

  • Angular + Ionic
  • TypeScript
  • SCSS
  • HTTPClient
  • API de Filmes
  • Pipes personalizados
  • Diretivas personalizadas
