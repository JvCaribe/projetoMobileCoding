Sim tá bem bagunçadinho, mas são exemplos práticos dos componentes que iremos usar. O resto fica pra galera da estilização

O que tem aqui:

  • Uma barra de pesquisa (que não funciona, mas tem o layout)
  • Um card (que não tem nada dentro, mas tem o layout)

Basicamente todos os componentes são puxados da API do ionic, então pra chamar eles vc tem q usar a tag específica deles, q é o nome do componente entre chaves "ion-nomedocomponente"
E depois o mais IMPORTANTE vc tem que adicionar a mesma tag no arquivo page.ts da página, no caso dessa é o home.page.ts. Aí você coloca no import do começo da página e depois nos imports do @Components

Pra mudar o fundo tem q ir na tag ion-content, q é a MÃE de todas aqui, tudo tá dentro dela, é a primeira tag, se quiser mudar algo pra testar. Apanhei bastante pra descobrir isso
